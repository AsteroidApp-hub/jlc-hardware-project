## 0. おすすめの順番

1. **国内の部品を先に買う** (下の「3. 国内購入」)。届くまで数日
2. **原寸チェック**: [原寸チェック](../原寸チェック/原寸チェック.html) の手順で、印刷した基板図に実物の部品を置いて穴・足の間隔を確かめる。
   合わない部品があれば、基板を直してから発注する (基板の作り直しは数千円と 2〜3 週間かかるため)
3. 問題が無ければ JLCPCB (基板) と JLCCNC (筐体) に発注する。人の設計者に見てもらう場合は、この前に
   回路図と [設計の根拠](../設計根拠/設計根拠.html) を渡す

## 1. JLCPCB (基板 + SMD実装)

https://jlcpcb.com/ → 「Order now」→ `P48_2CH_gerber.zip` をアップロード

### 基板の設定

| 項目 | 設定 |
|---|---|
| Base Material | FR-4 |
| Layers | **4** |
| Dimensions | 96 × 86 mm (自動で読み込まれる) |
| PCB Qty | 5 (最小) |
| PCB Thickness | **1.6 mm** |
| Impedance Control | No (スタックアップは標準 JLC04161H-7628 で可) |
| PCB Color | 緑 (好みで変更可。色によっては納期が延びる) |
| Surface Finish | ENIG 推奨 (無鉛HASLでも可) |
| Outer / Inner Copper | 1 oz / 0.5 oz |
| Via Covering | Tented |
| Remove Order Number | Specify a location ではなく **Yes (Remove)** を推奨 (シルクに番号用の場所を作っていないため) |

### SMD実装 (PCB Assembly)

| 項目 | 設定 |
|---|---|
| PCBA Type | **Economic** |
| Assembly Side | Top Side |
| PCBA Qty | 2 (最小。5枚すべて実装する場合は 5) |
| Tooling holes | Added by JLCPCB |
| Confirm Parts Placement | **Yes** (向きを担当者が確認してくれる) |

1. BOM に `P48_2CH_BOM.csv`、CPL に `P48_2CH_CPL.csv` をアップロード
2. 部品一覧で 27種類 すべてが **Basic** になっていることを確認 (Extended があれば追加料金がかかる)
3. **配置プレビューで向きを確認する** (下表)。ずれていたら画面上で回転して直す

| 確認する部品 | 正しい向き |
|---|---|
| Q2, Q3 (MMBT5551, SOT-23) | 足1本の側 (コレクタ) が右。CPLで −90° 補正済み |
| D1 (SS34), D3 (SS210) | 帯 (カソード) がシルクの K 側 |
| D4, D5 (1N4148W) | 帯 (カソード) がシルクの帯側 |
| その他 (抵抗・コンデンサ) | 向きなし |

R11, C15 (スナバ) は未実装 (DNP) のため BOM/CPL に入っていない。

## 2. JLCCNC (板金筐体)

`JLCCNC/JLCCNC発注メモ.md` の手順どおり。要点:

- ボトム・カバーを別々の部品として STEP をアップロード

- ボトムに M3 圧入ナット ×4 (図面 `筐体図面.pdf` を Riveting File に添付)
- 前後パネルに白シルク (`silk_front.dxf` / `silk_rear.dxf`)
- 備考欄の英文はメモに用意済み

## 4. 組立 (手はんだ)

JLCPCB から SMD実装済みの基板が届いたら、**背の低い部品から** 付ける。

| 順 | 部品 | 注意 |
|---|---|---|
| 1 | R102, R103, R202, R203 (6.81k 0.1%) | 向きなし。10 本を測って値の近い 2 本ずつを R102/R103、R202/R203 の組に |
| 2 | D2 (P6KE24CA、太いほう) と D101, D102, D201, D202 (P4KE15CA) | どれも双方向TVSなので向きなし。**D2 だけ型番が違う**ので取り違えに注意 |
| 3 | C105, C107, C205, C207 (WIMA MKP4 0.1µF) | 向きなし |
| 4 | F1 (MF-R050) | 向きなし |
| 5 | U1 (UC3843AN) | **切り欠き・1番ピンを四角パッドに**。ICソケットを使ってもよい |
| 6 | Q1 (IRFU120N) | 四角パッド = ゲート (G)。足の並びは G-D-S |
| 7 | J2 (XHヘッダー 3P) | PHANTOM スイッチ用 |
| 8 | 電解コンデンサ C1, C13, C16, C18, C101, C104, C106, C201, C204, C206 | **+ (長い足) をシルクの「+」側 (角の丸い四角パッド) に**。値の取り違えに注意 (C1 = 470µF/35V, C13/C16 = 47µF/100V, ほかは MUSE FW 100µF/100V) |
| 9 | L1 (トロイダル) | 向きなし。長穴の範囲で足を通す |
| 10 | LED1 | **短い足 (カソード) を四角パッドに**。LED先端が基板の前端から約0.7mm出る位置で、基板と平行に |
| 11 | J1 (DCジャック) | 側面ピン用の穴は両側にある。合う方を使い、もう一方は空きのまま |
| 12 | XLR ×4 | 最後に付ける。**はんだ付けの前に**、パネルに仮組みして位置を合わせると確実 |

電源スイッチは付けない (外部リニア電源側のスイッチを使う)。代わりに前パネルの **PHANTOM スイッチ (MS-500A-B, ON-ON)** を XHハウジング 3P の線で J2 へつなぐ。

| スイッチの端子 | J2 | 意味 |
|---|---|---|
| 中央 (共通) | 2番 (VBASE) | |
| レバーを **上 (ON)** にしたとき中央とつながる外側の端子 | 1番 (PH_FEED) | ON |
| もう一方の外側の端子 | 3番 (PH_OFF) | OFF |

一般的なトグルスイッチはレバーと**反対側**の端子が中央とつながる (レバー上 → 下側の端子)。念のためテスターで確認してから配線する。端子は熱収縮チューブで保護する。配線が外れた場合はファンタムが OFF になる (安全側)。

### 筐体への組み込み

1. ボトムの底板に M3×6 スペーサーを M3×4 ねじで固定 (ねじの下に歯付き座金)
2. 基板を載せて M3×4 で固定
3. XLR を前後パネルの内側からタッピンねじで固定
4. PHANTOM スイッチをパネルに固定し、配線を J2 へ
5. カバーを被せ、側面から M3×6 ×4 (歯付き座金つき) で固定
6. 底面にゴム足

## 5. 動作確認 (マイクを接続する前に)

**注意: 基板上には最大約52Vがかかる。通電中は基板に触れない。電源を切った後も数秒は電圧が残る。**

| 順 | 確認 | 期待値 |
|---|---|---|
| 1 | 通電前: DCジャックの + と − の間の抵抗 | 短絡していない (数kΩ以上) |
| 2 | PHANTOM スイッチを **OFF** にして、12〜18V のリニア電源を接続・電源ON。消費電流が測れるなら測る | マイクなしで 約20〜50mA (マイク 2 本接続時の計算値は約80mA) |
| 3 | C13 の + (VBOOST) と GND の間 | 約 51.5V (50〜53V)。この時点で C19 (+48V) は 0V 付近、LED 消灯 |
| 4 | PHANTOM スイッチを **ON**。約3秒待って C19 (+48V) と GND の間 | 約 48V (46.5〜49.5V)。LED がゆっくり点灯 |
| 5 | MIC IN の 2番・3番ピンと 1番ピンの間 (マイクなし) | それぞれ 約 48V |
| 6 | MIC IN の 2番と1番の間に電流計 (短絡電流) | 約 7mA (48V ÷ 6.81kΩ) |
| 7 | 10秒以上待って OUT の 2番・3番ピンと 1番ピンの間 | 0V 付近 (±1V以内) |
| 8 | PHANTOM スイッチを **OFF** | +48V が約3秒で 0V 付近へ。LED がゆっくり消灯 |
| 9 | 電源OFF後、C13 の電圧が下がることを確認 | 数秒〜十数秒で低下 |

すべて OK ならマイクと録音機をつなぐ。

### 使い方の注意

前面の LED は **ファンタム (+48V) が出ている表示** (PHANTOM スイッチに合わせてゆっくり点灯・消灯する)。

**使い始め**

1. PHANTOM を OFF にして電源を入れる
2. マイクと録音機をつなぐ (ファンタム OFF のうちにつなぐのがマイクにも録音機にもやさしい)
3. 録音機をミュート
4. PHANTOM を ON にして、LED が点いてから **約10秒** 待つ (出力の過渡電圧が収まるまで)
5. 録音機のミュートを解除

**終わるとき**

1. 録音機をミュート
2. PHANTOM を OFF にして、LED が消えるまで (約3秒) 待つ
3. マイクを外す・電源を切る

- 電源ごと切ると +48V が急に落ち、出力に約 −15V の過渡電圧が出る (TVS で制限)。PHANTOM スイッチで先に OFF にすれば約 −6V に収まる (シミュレーション T6)
- 録音機側のファンタム電源は **OFF** にしておく (この装置がファンタム電源を供給するため)
