# 外観・パネル配置と基板の構成 (回路図より先に決める)

## なぜ先に決めるか

ボタン・コネクター・LED の位置と、基板が 1 枚か 2 枚かで、基板の形、部品の並び、配線の取り回しが決まる。
回路図・基板・筐体を一気に作ってから配置を大きく変えると、筐体・基板・組立確認・資料をまとめて作り直すことになる。
外から見た配置図をユーザーに確かめてもらい、合意してから部品選定と回路図に進む。

## ユーザーと決めること

| 項目 | 聞き方・決め方 |
|---|---|
| パネルに出すもの | 入出力のコネクター、電源の入口、スイッチ、LED、つまみ。それぞれ前面か後面か |
| 置き方の基本 | 操作するもの (スイッチ・つまみ・表示) は前面、つなぎっぱなしのケーブル (出力・電源) は後面が多い。ユーザーの使い方を優先する |
| 印刷の文字 | 各部品の名前 (MIC IN、PHANTOM など)、スイッチの ON / OFF の向き、電源の電圧と極性 |
| 取付の種類 | 基板に付く部品 (基板用 XLR、DC ジャック、LED) は、高さが部品の寸法で決まり、横方向しか動かせない。パネルに付く部品 (トグルスイッチ、ボリューム) は高さも自由 |
| 間隔 | 部品の大きさ (XLR のフランジ、つまみの直径、ナット) と、指で操作する余白。穴と曲げ・パネルの端との距離 |
| 筐体の大きさ | 仮の外形。部品が決まっていなければ代表的な寸法で置き、部品選定のあとで直す |
| 基板の構成 | 電源部を音声と同じ基板にするか、別基板にするか (下の「基板の構成」) |

## 進め方

1. `tools/panel_layout.py` に外形、パネル部品の位置と穴、印刷の文字、`POWER_BOARD` を書く。
   型番が決まっていない部品は、代表的な寸法で仮に置く (あとで部品選定の結果に合わせて直す)。
2. `python3 tools/panel_layout.py` を実行する。外から見た前面・後面の配置図 (`パネル配置/前面.svg`・`後面.svg`) と、
   確認用のページ (`パネル配置/パネル配置.html`) ができる。穴がパネルからはみ出す所や、穴どうしが近すぎる所は自動で知らせる。
   CAD の環境は要らない。
3. 配置図と部品の一覧を見せて、ユーザーに確かめてもらう。「スイッチをもう少し右へ」のような直しを受けて 1〜2 を繰り返す。
4. 合意したら、決めたことをプロジェクトの `CLAUDE.md` に書き、部品選定と回路図に進む。

## 配置をあとで変えるとき

- 位置と印刷だけを変える: `panel_layout.py` を直し、配置図 → 筐体 (`gen_enclosure.py`) → 基板 (パネル近くの部品の `POS`) →
  組立確認 (`fit_check.py`) → 画像と資料 を作り直す。部品が変わらなければ、回路図とシミュレーションは作り直さない。
- 部品を替える (別の形のコネクターなど): フットプリントが変わるので、回路図の `PARTS` と購入リストも直し、照合と ERC を通す。
- どちらも、直したら配置図をもう一度ユーザーに見せる。

## 基板の構成 (電源部を同じ基板にするか、別基板にするか)

選ぶ前に、次の違いを示す。どちらが良いかは機器による。

| | 同じ基板 (1 枚) | 別基板 (2 枚) |
|---|---|---|
| 費用 | 基板が 1 種類で済む | 基板が 2 種類になる (JLCPCB は種類ごとに最低枚数と送料がかかる)。基板をつなぐコネクターと配線も増える |
| 雑音への対策 | 配置と GND の引き回しで対策する (スイッチング部を音声から離す、GND を 1 点でつなぐ) | スイッチング電源を物理的に離せる。音声の基板にコイルや大きな電流のループを置かずに済む |
| 組立 | 配線が少なく簡単 | 基板どうしの配線、取付穴とスペーサーが増える。筐体の中の置き方も決める |
| 作り直し | 電源を変えると全体を作り直す | 電源だけ、音声だけを作り直せる。電源の基板をほかの機器に流用できる |
| 向いている場合 | 小型で電流が小さく、シミュレーションで雑音が十分に下がると確かめられる設計 (雛形の 2ch P48 はこちら) | 大きな電流、雑音に敏感な回路 (ゲインの高いマイクプリなど)、電源を共用・流用したいとき |

雛形は 1 枚の構成。別基板を選んだときは次のように作る。

- 回路図と基板は基板ごとに作る (KiCad のプロジェクトを 2 つ。回路図はそれぞれ 1 枚にすべてつながった形)。
  `PARTS` も基板ごとに分け、基板どうしをつなぐコネクター (電源のライン、GND) を両方の回路図に置く。
- GND は 1 か所でつなぐ (ループを作らない)。電源の基板からの配線の抵抗と、コネクターの定格電流を確かめる。
- シミュレーションは、2 枚と配線をまとめた全体で行う (配線の抵抗を入れる)。
- `panel_layout.py` と筐体に、2 枚目の基板の位置・取付穴・スペーサーの高さを足し、組立確認で 2 枚とも干渉を確かめる。
- 製作者向け資料に、基板どうしの配線表 (線の色・長さ・ピンの対応) を入れる。
