# 板金筐体 (JLCCNC)

## JLCCNC の条件 (2026-11 時点の公式ページより)

- 板金のアルミは A5052 のみ (0.5〜6mm)。他にステンレス 201/304、冷間圧延鋼、亜鉛めっき鋼。
- **STEP の 3D データが必須**。2D (PDF/DXF) は補助。展開してくれるかは明記なし → 展開図 DXF を参考に添付すると安全。
- 圧入ナット・スタッド M2.5〜M10 可 (「Thread or Riveting File」に図面を添付)。溶接は標準外。
- 表面処理: アルマイト (9色)、硬質アルマイト、**導電アルマイト**、粉体塗装 (7色)、シルク印刷、レーザー刻印。
- シルク・刻印は「曲げた後の形」の DXF/DWG、文字は二重線 (アウトライン) フォント。
- 外R (曲げ外側の半径): 1.5mm 板で 2.75mm (内R 約 1.25mm)。曲げの最小フランジ長・穴と曲げの距離は画像のみで数値が読めなかった
  → 一般的な目安 (穴の縁を曲げから板厚の 2〜3倍以上離す) で設計し、レビュー指摘があれば調整する。
- 公差: 一般 ±0.2、穴 ±0.1、曲げ ±0.3、角度 ±1°。自動見積は参考値で、手動レビュー後に確定。

## 雛形の構造 (`tools/enclosure/gen_enclosure.py`)

- **ボトム** = 底板 + 前後パネル + 左右の低い立ち上がり (圧入ナット)、**カバー** = 天板 + 左右側板。カバーは側面のねじで固定するので
  天面にねじ頭が出ない。
- 圧入ナットは「外側が平ら・本体が内側」に指定する (外側にカバー側板が密着するため)。フランジ付きのリベットナットは不可。
- 基板はスペーサーで浮かせる (`STANDOFF`)。コネクタの中心高さ = 基板上面 + コネクタの軸高さ。天板までの余裕を実部品の高さで確認。
- 出力: 部品ごとの STEP、組立 STEP、展開図 DXF (K ファクター)、シルク DXF、寸法図 PDF、プレビュー画像、`pcb_constraints.json`
  (基板設計へ渡す寸法)。
- アルマイトは絶縁なので、シャーシ接地は歯付き座金で塗膜を破る (または導電アルマイト)。

## 位置を決めるときの注意

- パネル取付コネクタの「パネルに当たる面」はフランジ前面ではなく、ねじボスの前面のことがある (Neutrik NC3FAAH2 は STEP の z=5.5)。
  モデルを置いて干渉体積を計算し、0 になる位置を確かめる。
- ラッチボタン (PUSH) などパネルの外に出る部分は干渉に見えることがある。どの部分か切り出して確認する。
- DC ジャックは前面をパネル内面に揃える (奥まっているとプラグが奥まで入らない)。基板の端から張り出させてよい。
- 横向き LED は「LED 中心の高さ」(フットプリント名の Z) からパネル穴の高さを決める。
- パネルスイッチの真下は高い部品を置かない (本体の奥行きと高さを確認)。

## 干渉チェック (`tools/enclosure/fit_check.py`)

```sh
kicad-cli pcb export step --subst-models -o board.step kicad/<PROJECT>.kicad_pcb
<venv>/bin/python tools/enclosure/fit_check.py board.step <メーカー STEP フォルダ>
```

KiCad の STEP は x = KiCad X、y = −KiCad Y、z = 基板下面 0。筐体座標へ平行移動して、部品ごとに筐体との交差体積と最高点を出す。
KiCad の 3D モデルが無い部品 (自作フットプリント、一部コネクタ) は高さを手で確認する。

## 3D の見た目確認

matplotlib の 3D は前後関係が崩れるので、PyVista (VTK) のオフスクリーン描画を使う。面ごとに三角形分割し、分割できない面は飛ばす。
