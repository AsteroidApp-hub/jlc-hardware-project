# 部品選定と購入先

## 方針の決め方

- JLCPCB の SMD 実装は「基本部品 (Basic)」なら部品ごとの段取り料金がかからない。拡張部品 (Extended) は 1種類ごとに追加料金。
  ユーザーがコストを重視するなら基本部品だけで組み、無理な部品はスルーホール品にして国内通販で買って手はんだにする。
- 基本部品は数百点しかない。昇圧・降圧 IC、100V 級 MOSFET、電解コンデンサ、0.1% 抵抗、高耐圧 TVS、フェライトの一部などは無いことが多い
  (2026-11 時点で 351 点)。回路方式そのものを「基本部品 + 手はんだ部品」で組める形に寄せる (例: SMD の昇圧 IC をやめ、DIP の UC3843 + THT MOSFET)。

## JLC 基本部品の確認

`scripts/jlc_basic_parts.py` を使う。

```sh
python3 scripts/jlc_basic_parts.py update          # 全件取得 (キャッシュ)
python3 scripts/jlc_basic_parts.py types           # 何の種類があるか
python3 scripts/jlc_basic_parts.py res 0603 4.7k   # 抵抗 (UNI-ROYAL の型番から値を読む)
python3 scripts/jlc_basic_parts.py cap 0805 100n 50    # 容量・最低耐圧で検索
python3 scripts/jlc_basic_parts.py diode schottky 40   # ダイオード (schottky / switching / tvs …)・最低耐圧
python3 scripts/jlc_basic_parts.py find MOSFET         # 文字列で検索 (説明欄に耐圧・電流なども出る)
python3 scripts/jlc_basic_parts.py check C17415 C2145  # BOM の LCSC 番号が基本部品か
```

- 基本部品の MLCC は 50V 以下が大半 (100V は 0805 100nF などごく一部)。高電圧側の大容量は電解 (手はんだ) にする。
- DC バイアスで X5R/X7R の容量は大きく下がる (10µF/50V 1206 を 12V で使うと実効 5〜6µF 程度)。シミュレーションに反映する。
- 抵抗は 0402〜1206 の E24 系の主な値がある。1206 は値が少ない (0, 0.1, 1, 10, 20, 22, 100, 120, 300, 1k, 2k, 4.7k, 10k, 100k, 1M 程度)。
- 検索はすべて JLCPCB の API の説明欄 (`describe`: 値・耐圧・誤差・パッケージ) から行う。外部の検索サイトは使わない。
- 基本部品にツェナーダイオードは無い (2026-11 時点)。TVS は 3 点のみ (低電圧の ESD 用が中心)。

## 国内通販の調べ方

| ショップ | 調べ方 | 備考 |
|---|---|---|
| 秋月電子通商 | `https://akizukidenshi.com/catalog/goods/search.aspx?search=x&keyword=キーワード`、商品ページは `/catalog/g/gNNNNNN/` | 価格は税込。データシート PDF は `/goodsaffix/...` |
| Digi-Key Japan | `https://www.digikey.jp/ja/products/result?keywords=型番`、詳細 `/ja/products/detail/<maker>/<型番>/<id>` | 税抜表示。在庫・ライフサイクル (新規設計非推奨など) を確認 |
| 千石電商 | `https://www.sengoku.co.jp/mod/sgk_cart/search.php?multi=キーワード`、商品 `/mod/sgk_cart/detail.php?code=...` | 税込。オーディオ部品は限られるが、ねじ・スペーサー類が豊富 |
| マルツ | 自動アクセスは 403 になることが多い | 手で確認してもらう |

- ページは web-fetch 用のエージェント (またはツール) で読む。**実際に読み込んだページの値だけ**を使い、検索結果の一覧だけで決めた品は
  「一覧のみ・商品ページ未確認」と記録する。
- **購入リンクは必須。** 商品ページの URL を付ける。Digi-Key の `products/result?keywords=<型番>` は 1 件に絞れると商品ページが直接開くので、
  開いて確認できたら使ってよい。JLC 実装部品は `https://jlcpcb.com/partdetail/<LCSC番号>` で部品ページが開く。
- JLC 部品の型番 (MPN) は、JLC の基本部品データ (`componentModelEn`) と合わせる。同じ仕様でも別メーカー品のことがある (LCSC 番号が正)。
- 在庫・価格は日付つきで残す (購入リストに「◯年◯月◯日時点」)。
- 同じ型番でも枝番で別物のことがある (例: LM2577 の ADJ と固定電圧品)。型番は完全一致で確認する。

## 送料をまとめる

部品代が数千円の機器では送料の比重が大きい。購入リストを作ったら、店ごとの送料と送料無料の条件を調べて表にする。

- 店の数を最小にする。「その店でしか買えない部品」がある店を先に決め、ほかの部品はその中でまとめる。
- 送料無料まで少し足りないときは、**足りない額と送料を比べる**。ほぼ同額なら、まとめ買いの単価が下がる数量 (10個単価など) や
  予備を足して届かせる (送料に払うより部品が手元に残る)。大きく足りないなら送料を払う。
- ねじ・スペーサーなどの小物だけの注文は、メール便 (ネコポス等) を選べる店にすると安い。
- 税込か税抜かの判定が不明な条件は、安全側 (税抜で届かせる) にしておく。
- 2026-11 時点の例: Digi-Key Japan は ¥6,000 未満で送料 ¥2,000 (以上は無料)、秋月は 1個口 ¥550 (税込 ¥11,000 以上で無料)、
  千石電商は ¥660 (ネコポス ¥350、¥10,000 超で無料)。千石は M3 の金属スペーサー (メス-メス)・歯付き座金・タッピンねじがある。
- 雛形の `gen_schematic.py` には `SHIPPING` (送料・無料条件) と `spare` / `tier10` (予備と10個単価) があり、購入リストに送料込みの
  合計表が出る。Digi-Key が無料条件に届かなければ止まる。

## データシートで確認すること

- ピン配置・ピン間隔・穴径 (フットプリントを作る/選ぶため)。記載が無い寸法は長穴にするなどで吸収し、「実物で確認」に残す。
- 外形と高さ (筐体の高さ制限)。電解は同じ容量でも耐圧で高さが変わる (例: 100µF/63V φ10×12.5、100µF/100V φ10×20)。
- 絶対最大定格 (例: MOSFET のゲート ±20V。入力電圧を上げると UC3843 の出力がそのままゲートにかかる)。
- PDF が文字で読めないときは `sips -s format png` (macOS) などで画像にして読む。図面の向きに注意。

## オーディオ系でよく使う判断

- ファンタム電源 (P48) の経路のコンデンサは **最大 52V** がかかる。耐圧 63V 以上、余裕を見るなら 100V。50V 品 (MUSE ES 等) は不可。
- 給電抵抗 6.81kΩ は 0.1% 品 (TE YR1 など) で揃えると、電源ノイズが差動信号に化けにくい。
- フィルムは WIMA MKP (ポリプロピレン) が定番。国内在庫は Digi-Key で確認 (秋月は Rubycon MPS が中心で生産終了告知あり)。
- 手に入りにくい銘柄 (MUSE KZ、ELNA Silmic II の高耐圧品など) は早めに在庫を確認し、代替候補をリストに書く。

## 購入リスト

雛形の `gen_schematic.py` の `SHOP` (ショップ・品名・URL・単価・入数・税表示) と `EXTRA_BUY` (基板に載らない部品)、
`OTHER_BUY` (ホームセンター等の汎用品) を書くと、`部品購入リスト.md/.html` が自動で作られる。
10個単価が安い品は `tier10` で推奨購入数を調整する。
