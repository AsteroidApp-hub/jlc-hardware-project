# 実例: 2ch P48 ファンタム電源 (P48)

雛形 (`assets/template/`) はこの機器そのもの。似た機器を作るときの判断の参考に。

## 仕様

DC 12〜18V (外部リニア電源) → UC3843 昇圧 51.5V (153kHz、常に電流不連続モード) → RC フィルター (22Ω + 47µF) →
トランジスタ 2段のリップルフィルター (基準 = R13/R14 の分圧 + C18、約 1秒の時定数) → +48.2V → ch ごとに 100Ω + 100µF →
6.81kΩ 0.1% で P48 給電 → DC カット (MUSE FW 100µF/100V + WIMA MKP4 0.1µF) → 10Ω + 10kΩ ブリーダー + TVS → 出力 XLR。
前面に PHANTOM スイッチ (基準電圧側を切り替え、+48V を約 2秒でゆっくり上下)。基板 96×86mm 4層、筐体 110.4×91×39mm A5052。

## 経緯と判断

| 段階 | 問題・要望 | 判断 |
|---|---|---|
| 電源方式 | AC トランス式だとハムの心配 | PSE 付き DC アダプター (後にリニア電源) + 内部昇圧 + リップルフィルター |
| 部品 | 「基本部品のみ」「国内通販」の方針 | SMD 昇圧 IC (LM51551, 拡張部品・手はんだ困難) → DIP の UC3843 + THT MOSFET に変更 |
| 部品 | フェライトビーズ禁止 | 入力は直結、昇圧出力は RC フィルター |
| 起動 | インダクター電流ピーク 1.21A > SRC1013 定格 1.1A | 3A のトロイダル TCV-101M-3A (秋月、¥50) に変更、ピン間隔不明は長穴で吸収 |
| 出力過渡 | 録音機未接続で電源 ON すると出力 +15V が長く残る | ブリーダー 47k → 10k (+10.8V、早く抜ける) |
| 音質 | MUSE ES (50V) を使いたい | P48 経路は最大 52V のため不可、MUSE FW 100V に (同寸法で差し替え) |
| 電源電圧 | 18V / 24V も用意可 | 18V 可 (入力 TVS を 24V 品に)。24V は MOSFET ゲートが 22V で定格超え → 非対応 |
| 操作 | 電源スイッチ不要、ファンタム ON/OFF が欲しい | +48V を直接切らず、リップルフィルターの基準を SPDT で切り替え (OFF 時の出力過渡 −15V → −6V) |
| 資料 | 資料は HTML で読みたい (Markdown は不可) | すべて HTML + 入口ページ。製作は別の人 → 製作者向け資料と zip |

## シミュレーションで分かったこと

- +48V に残るスイッチング成分 約 0.5µV、マイク給電点 約 3nV (リップルフィルター + ch ごとの RC が効く)
- 負荷急変 (+16mA) で 0.1V 下がり 5ms 以内に振動せず戻る (位相補償 R4 1MΩ + C10 47nF + C11 100pF)
- 帰還の積分の時定数 (約 47ms) が長いため、最後の整定はゆっくり (+48V には影響しない)

## 実物で確認が残った点

トロイダルの足の間隔、パネルスイッチの奥行き、スイッチのレバーと端子の対応、DC ジャックの側面ピン、JLC 配置プレビューでの向き、
JLCCNC の曲げ制約。
